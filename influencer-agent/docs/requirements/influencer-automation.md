# 要件定義: インフルエンサー採用自動化システム

## 概要

OpenClawエージェント（Eddie）を活用し、B2Cアプリのインフルエンサーマーケティングにおける
リーチ→交渉→契約→フォローアップの6ステップのうち60%を自動化するシステム。

## ユーザーストーリー

### US-1: インフルエンサー発見
AS A アプリ運営者
I WANT TO 条件に合うインフルエンサーを自動で発見したい
SO THAT 手作業での検索時間を削減し、より多くの候補者にリーチできる

### US-2: 自動アウトリーチ
AS A アプリ運営者
I WANT TO 発見したインフルエンサーに自動でメール/DMを送信したい
SO THAT VA（月$400）を雇わずに10倍のパフォーマンスを実現できる

### US-3: リード管理
AS A アプリ運営者
I WANT TO インフルエンサーの反応を一元管理したい
SO THAT 交渉ステータスを把握し、適切なフォローアップができる

### US-4: KPIモニタリング
AS A アプリ運営者
I WANT TO アウトリーチの成果を毎日把握したい
SO THAT 戦略の改善とROI最適化ができる

## 受入条件

### 機能要件

#### Phase A: インフルエンサー発見 (Discovery)
- [ ] A-1: Instagramハッシュタグ/キーワードベースでインフルエンサーを検索できる
- [ ] A-2: フォロワー数（デフォルト: 10K〜50K）でフィルタリングできる
- [ ] A-3: 平均再生数（デフォルト: 10K+）でフィルタリングできる
- [ ] A-4: ニッチ/カテゴリをパラメータとして指定できる
- [ ] A-5: バイオからメールアドレスを正規表現で抽出できる
- [ ] A-6: リンク先ウェブサイトからもメールを取得できる
- [ ] A-7: 結果をJSON/CSVで出力しローカルDBに保存できる
- [ ] A-8: Grok x_searchでX上の活動も補完的に調査できる（将来対応可）
- [ ] A-9: 重複インフルエンサーを検出・除外できる

#### Phase B: メールアウトリーチ (Email Outreach)
- [ ] B-1: Smartlead APIでキャンペーンを自動作成できる
- [ ] B-2: Claude APIでインフルエンサーごとにパーソナライズされたメールを生成できる
- [ ] B-3: 1日最大1,000通のメールを送信できる
- [ ] B-4: 4〜5ステップのフォローアップシーケンスを自動実行できる
- [ ] B-5: CPM提案テンプレートをカスタマイズできる
- [ ] B-6: CAN-SPAM準拠（物理住所、配信停止リンク）
- [ ] B-7: バウンス/スパム報告を自動処理し送信リストから除外できる

#### Phase C: DM自動化 (Optional - 高リスク)
- [ ] C-1: Instagram DMを1日最大100通送信できる
- [ ] C-2: アカウントウォームアップ機能がある
- [ ] C-3: BAN回避のためのレート制限と間隔設定ができる
- [ ] C-4: DM送信のON/OFFを設定で切り替えられる

#### Phase D: リード管理 & フォローアップ
- [ ] D-1: インフルエンサーのステータス管理（発見→連絡済→返信あり→交渉中→契約済→却下）
- [ ] D-2: Smartlead Webhookで返信を自動検知できる
- [ ] D-3: 返信内容をClaudeで分析し、カテゴリ分類できる（興味あり/質問/拒否/不在）
- [ ] D-4: 「興味あり」返信にはエスカレーション通知をTelegramに送信
- [ ] D-5: フォローアップメールを自動スケジュールできる

#### Phase E: KPIレポート
- [ ] E-1: 日次レポートをTelegram/コンソールに出力できる
- [ ] E-2: レポート項目: 送信数/開封率/返信率/リード獲得数/パイプライン状況
- [ ] E-3: 週次サマリーで傾向を分析できる

### 非機能要件
- **パフォーマンス**: 1,000メール/日 + 100DM/日を安定処理
- **信頼性**: 失敗時のリトライ機構、エラーログ
- **セキュリティ**: APIキーは環境変数管理、Instagram認証情報の安全な保管
- **拡張性**: ニッチ/フィルタ条件をconfig.yamlで変更可能
- **コスト**: 月$500以内で運用可能

## 制約事項

### 技術スタック
- **エージェント基盤**: OpenClaw（インストール済み）
- **言語**: Python 3.11+（スクリプト/Skill実装）
- **インフルエンサー発見**: Apify Instagram Profile Scraper API
- **メール配信**: Smartlead API（推奨）またはInstantly.ai API
- **AI生成**: Claude API（メールパーソナライゼーション）
- **X検索**: xAI Grok API（将来対応、APIキー未取得）
- **DM自動化**: instagrapi（オプション、高リスク）
- **通知**: Telegram Bot API
- **データ保存**: SQLite（ローカル）またはJSON
- **設定管理**: YAML config

### 外部サービス要件
| サービス | 必須/任意 | 推定月額 |
|---------|----------|---------|
| Apify (Starter) | 必須 | $29 |
| Smartlead (Pro) | 必須 | $94 |
| Google Workspace (34 accounts) | 必須 | ~$210 |
| ドメイン (10-12個) | 必須 | ~$12/mo |
| Claude API | 必須 | ~$30-90 |
| xAI Grok API | 任意 | ~$5-30 |
| Telegram Bot | 必須 | 無料 |
| **合計** | | **~$380-465/mo** |

### Instagram ToSリスク
- メール抽出: 公開データのスクレイピングは法的グレーゾーン（Apify経由で低リスク）
- DM自動化: ToS違反リスク高。Phase Cはオプション機能として実装
- アカウントBAN対策: 住宅プロキシ使用、レート制限遵守

## 6ステップ自動化マッピング

| # | ステップ | 自動化レベル | 実装方法 |
|---|---------|-------------|---------|
| 1 | インフルエンサーへのリーチ | **100% 自動化** | Apify発見 → Claude生成メール → Smartlead送信 |
| 2 | 自己紹介 + 情報収集 | **80% 自動化** | テンプレートメール + 返信分析 |
| 3 | CPM交渉 | **30% 自動化** | Claude提案生成 → 人間が最終判断 |
| 4 | 契約 + オンボーディング | **手動** | 人間が契約書作成・署名 |
| 5 | コンテンツ指導 | **50% 自動化** | テンプレートガイド送信 → 人間がレビュー |
| 6 | フォローアップ | **90% 自動化** | 自動リマインダー + 投稿確認 |

**全体自動化率: 約60%**（記事のEddie同等）
